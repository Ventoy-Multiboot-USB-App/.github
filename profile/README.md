## 🚀 Overview
If you have ever burned one ISO to a USB stick only to reformat it a day later for a different image, Ventoy for Windows solves that problem for good. It is a free, open-source tool that prepares a USB drive once and then lets you manage bootable images the same way you manage any other files — by copying them on and deleting the ones you no longer need. At startup Ventoy presents a clean boot menu listing every image on the drive, and it handles Legacy BIOS, UEFI and Secure Boot so your stick works on both older and modern hardware. Because the whole workflow is drag and drop, learning how to use Ventoy takes minutes, and a single well-stocked Ventoy USB can replace a whole shelf of single-image drives.

## ✨ Features
- **Install once, reuse forever** — set up Ventoy on the USB a single time, then add or remove ISO, WIM, IMG, VHD and EFI files freely without ever reformatting.
- **Automatic boot menu** — every image you copy onto the Ventoy USB appears in a tidy startup menu, so choosing what to boot is a single keystroke.
- **Secure Boot friendly** — Ventoy Secure Boot support means your images load on modern UEFI machines without disabling firmware protection.
- **Works on old and new PCs** — full Legacy BIOS and UEFI compatibility keeps one drive usable across a mixed fleet of computers.
- **Handles large images** — support for exFAT and NTFS on the USB lets you store big Windows install files that would not fit on a plain FAT32 stick, a practical edge when weighing Ventoy vs Rufus.

## 📥 Installation

## 🎯 Getting Started
1. Connect the USB drive you want to turn into a boot drive and open Ventoy.
2. Pick the right drive from the list and click **Install** — this wipes the USB, so save anything important first.
3. When it finishes, browse to the Ventoy partition in File Explorer.
4. Copy your ISO, WIM, IMG or VHD files onto the drive.
5. Reboot, start from the USB, and select an image from the Ventoy menu to launch it.

## ❓ FAQ
**Is Ventoy free?**
Yes. Ventoy is completely free and open source, with its full code hosted on GitHub for anyone to inspect or contribute to.

**Which versions of Windows are supported?**
You can run Ventoy on 64-bit editions of Windows from Windows 7 up to Windows 11. Using a currently supported release is recommended.

**Is Ventoy safe to use?**
Because Ventoy is open source, its behavior is transparent and reviewable, and Secure Boot support helps it run on protected systems. Just remember that preparing a drive erases it, so back up the USB before installing.

**How does Ventoy compare to Rufus?**
Rufus writes a single image and generally needs reformatting to swap it, while Ventoy keeps many images on one drive that you update by copying files. For juggling several ISOs, Ventoy is usually the quicker choice.

**Is my data secure?**
Ventoy runs entirely on your own computer with no account required. The install step clears the USB, so back it up first; anything you copy on afterward stays on the drive like ordinary files.
